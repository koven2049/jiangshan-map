# 开发与部署约定

开发检出和生产目录分开。部署前读取工程的 AGENTS.md 和部署说明，核实目标、运行账户与当前服务状态。

- 工程提供 `manage.sh` 时，使用它管理服务。同机发布用 `./manage.sh deploy-local`，跨机发布用 `./manage.sh deploy`。
- 部署只同步代码和依赖清单。用 `.rsync-exclude` 保护数据库、日志、上传物、缓存、配置与密钥。首次部署或排除清单变更后，先核对同步预览。
- 部署成功后由发布入口标记生产副本。常驻服务按目标平台使用 macOS 系统 LaunchDaemon 或 Linux systemd，具体以工程的部署配置为准。
- 通过反向代理或隧道开放服务时，分别核对 DNS 记录与后端路由。HTTP 服务部署后验证健康检查和一个关键只读端点。
- 共享工程规则与服务启停独立管理。维护本文件时只保留可公开的部署原则，机器、账户、连接地址和实际服务清单以授权环境中的运维文档为准。
